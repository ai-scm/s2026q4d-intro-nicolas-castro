## 1. Negocio y metodología

**Modelo 4P + 1T:** Personas · Proceso · Producto · Proyecto · Herramienta → **Potencial de negocio**

**Metodología ágil:**
1. **Iterativo:** ciclos de desarrollo que entregan partes del producto.
2. **Feedback:** el avance se revisa con el cliente.
3. **Product Backlog:** tareas definidas para la semana.
4. **Estimación:** tiempo de cada tarea (ej. *Planning Poker*).
5. **Daily:** sesión de 15 min para mantener al equipo al tanto.

## 4. Houndoc y referencia de arquitectura

**Houndoc:** plataforma que gestiona los módulos de Blend.
`AWS exámenes` → `Blend Colombia Skills` → `Nadia`

**Nadia (IA):**
- **Bedrock:** servicio de AWS que provee el modelo fundacional (LLM).
- **RAG:** agrega información complementaria a las respuestas.
- **ELK:** indexa documentos como fuente de conocimiento del agente.

**Círculo de confianza:** un único punto gestiona el ingreso y las credenciales.
- **IdP (Identity Provider):** autentica al usuario mediante **IAM**.
- **SP (Service Provider):** aplicaciones que confían en el IdP.
- **Reutilización:** usar módulos que ya funcionan en lugar de reinventar la rueda.
